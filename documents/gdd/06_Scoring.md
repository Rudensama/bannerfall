## 6. Scoring [LOCKED]

- Score = **destroys + combos**, never flat-per-ball.
- **Combo multiplier persists across shots [6b LOCKED]** — build it up, and don't break it. This is what gives "survive long" its teeth in a clockless game.
- **Combo resets to ×1 at the start of each stage [6d LOCKED]** — every stage is a self-contained scoring challenge.
- **6c — Combo rules [LOCKED]:**
  - To **grow/keep** the combo, a hit must **chain at least N balls** (N tunable). This is a **base-game rule**.
  - A **sub-N hit resets the combo to ×1** (you must chain to keep it — single pokes don't build combo, which would otherwise make scoring trivial). *(Tuning risk: if random ammo forces too many small matches and combos become unreachable, soften "reset" → "hold." Locked as reset for now.)*
  - A **mismatch shot also resets the combo to ×1.**
  - Bosses can **raise N** to make the chain requirement harsher (see §7b "The Demanding").

- **Banner scoring order [LOCKED]:** base shot score is computed first, **then Banners apply in placement order** (Balatro-Joker style — the order you slot Banners changes the math).
